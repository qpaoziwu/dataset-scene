# Synthetic dataset scene

Interactive case study for [richardhui.com/dataset](https://www.richardhui.com/dataset/): a tabletop scene from a multi-view 3D reconstruction spec, rendered in real time (Babylon.js) or path traced (three-gpu-pathtracer), with depth, normal, semantic and instance maps and the camera numbers saved for every view.

`assets/` holds what the page loads: the iPhone model, measured-material lookup tables (Physically Based, CC0), texture thumbnails and Babylon's blue-noise texture (CC0). Textures and HDRIs load from Poly Haven's CDN (CC0).
